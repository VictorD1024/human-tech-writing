# 可复制的中文提示词

## A：从材料写作

```text
请只根据我提供的材料写作。第一段直接给判断、事实或问题，不用“随着……的发展”开场。每段都要新增事实、判断或必要解释；优先保留数字、日期、人名、原话、动作和结果。把抽象名词改成主体明确的动作，句长和段长自然变化。少用成套连接词，不要自动升华或号召。证据不足就标出边界，不许补写我没提供的案例、数字和引语。完成后默读自检，删掉重复、空话和约 10%–20% 的冗余，但不要损失事实。
```

## B：重写已有 AI 稿

```text
请重写下面的稿件，保留原意、事实、专有名词和不确定性。删除空洞的重要性声明、重复结论、机械过渡和没有主体的抽象动作；把能够具体化的地方写成“谁做了什么，结果怎样”。打破均匀的句长和段落结构，但不要故意口语化。敢下材料能够支撑的判断，证据不足就明确说不足。不许编造例子、数字、引语或来源；缺少关键材料时先问我。结尾落在具体动作、决定、待验证问题或后果上。交稿前再删掉约 10%–20% 的冗余。
```

## C：只改语气，不动结构

```text
只调整下面文字的语气和句式，不改变段落结构、标题层级、信息顺序、事实或结论强度。去掉官腔、套话、机械连接词和重复表达，让句子更直接、自然，长短有变化。不要添加任何新案例、数字、引语、观点或来源，也不要擅自改写成另一种体裁。
```
